# COMP1238 Study Notes

## Week 1 - Information Storage Before Computers
- Writing systems allowed people to record information before computers. Chinese and Mesoamerican writing systems probably developed independently.
- Clay tablets were a durable material for storing cuneiform writing.
- Woodblock printing was used in China. The Diamond Sutra, dated 868 AD, is the earliest known printed text with a recorded production date.
- The printing press helped information spread widely and contributed to the Protestant Reformation.
- A typeface is the design of letters, while a font refers to a particular size and weight of that design.
- The terms uppercase and lowercase came from the upper and lower drawers used to store printing letters.
  
## Week 2 - Representation of Text and Numbers in Computers
- A bit is a binary digit that can hold either 0 or 1. One byte contains 8 bits and has 256 possible values.
- RAM is fast, temporary working memory. It is volatile, meaning its data is lost when the power is turned off.
- Non-volatile storage, such as hard drives and flash drives, keeps data when the power is turned off.
- Binary uses base 2, decimal uses base 10, and hexadecimal uses base 16. Hexadecimal uses digits 0-9 and letters A-F.
- Binary place values are powers of 2. For example, 0b1010 equals 8 + 2 = 10 in decimal.
- Hexadecimal place values are powers of 16. For example, 0x2F equals (2 × 16) + 15 = 47 in decimal.
- An unsigned integer with 16 bits can store values from 0 to 65,535.
- Fixed-point representation uses a fixed position for the decimal point, such as storing prices in cents. Floating-point representation allows the point's position to vary.
- ASCII stands for American Standard Code for Information Interchange. It assigns numeric codes to characters and control commands, such as line feed.
- All files are sequences of bytes. Text files interpret those bytes using a character encoding, while binary files can contain data such as audio or images.

## Week 3 - Structure of Text
- Text is organized using lines, spaces, indentation and paragraphs. This structure makes it easier to read.
- Alphanumeric characters are letters and digits. Non-alphanumeric characters include punctuation and symbols such as #, & and brackets.
- Markup languages provide instructions for displaying or interpreting text. The raw view shows the markup, while the rendered view shows the formatted result.
- Markdown is a simple markup language used for documentation. It uses symbols such as # for headings and - for bullet lists.
- HTML stands for HyperText Markup Language. Browsers interpret HTML tags to display web pages.
- JSON stands for JavaScript Object Notation, and XML stands for eXtensible Markup Language. Both store structured data in a text format that software can read.
- Escaping lets a special character appear as ordinary text. In Markdown, \# displays a literal # instead of creating a heading.
- HTML uses character references to display reserved characters. For example, &lt; displays < and &gt; displays >.
- Unicode assigns codepoints to characters from many writing systems and to symbols such as emojis.
- UTF-8 uses 1 to 4 bytes per Unicode codepoint. ASCII characters use 1 byte and have the same encoding in ASCII and UTF-8.

## Week 4 - Manipulating Text
- Keyboard layouts have three parts: physical layout is the arrangement of keys, visual layout is their labels, and functional layout is how software responds to them.
- Modifier keys, such as Shift, Ctrl and Alt, change the action of another key.
- Useful keyboard shortcuts include Ctrl+C to copy, Ctrl+V to paste and Ctrl+Z to undo.
- Touch typing means typing without looking at the keyboard. Regular practice helps improve accuracy and speed.
- Text editors, such as Notepad and VS Code, edit plain text and code. Word processors, such as Microsoft Word, also manage document formatting.
- IDE stands for Integrated Development Environment. It combines a text editor with other tools for developing software.
- A GitHub repository can be opened in the browser-based VS Code editor by changing github.com to github.dev in its address.
- In VS Code, Ctrl+F searches the current file, Ctrl+Shift+F searches across files, and Ctrl+H opens find and replace.
- Wildcards help match filenames. For example, *.txt matches filenames ending in .txt.
- Regular expressions describe search patterns. [0-9] matches a digit, [a-z] matches a lowercase English letter, and [abc] matches a, b or c.
- In regular expressions, + means one or more repetitions. For example, CAD[0-9]+ matches CAD followed by one or more digits.
- The pattern <h[1-6]> matches opening HTML heading tags from <h1> through <h6>.


## Week 5 - Text-Based Communication Between a Human and a Computer
- CLI stands for Command Line Interface. Users type a command, press Enter and receive a response from the computer.
- Command lines are useful for precise control, automating repetitive tasks and working remotely using few computer resources.
- Commands can include arguments and options that specify what they act on and how they behave.
- Common Unix-style commands include ls to list files, pwd to show the current directory, and cd to change directories.
- cat and less display text files. cp copies files, mv moves or renames files, and mkdir creates directories.
- grep searches for matching text in files and can use regular expressions.
- The > operator redirects output to a file, replacing its existing contents. The >> operator appends output to the end of a file.
- A pipe, written as |, sends the output of one command into the input of another command.
- The < operator lets a command read input from a file.
- The Unix philosophy encourages small programs that do one task well and work together using text streams.
- SSH stands for Secure Shell. It provides an encrypted connection for running commands on a remote computer.
- scp and sftp transfer files between computers. Tab can autocomplete commands or filenames, and passwords may remain invisible while being typed.
